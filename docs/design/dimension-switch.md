## 1. 한 세계, 두 시점

| | 2D (옆에서 본 평면) | 3D (등 뒤 3인칭) |
|---|---|---|
| 보이는 것 | 좌우 + 높이. 깊이는 한 줄로 겹침(투영) | 좌우 + 깊이 + 높이 |
| 판정 | **깊이 무시** — 좌우·높이만 겹치면 맞음 | 바닥 모양(부채꼴·원·직사각형) + 높이 |
| 이동 | A/D 좌우, Space 점프 | WASD, Space 점프 |
| 강점 | 정밀·타이밍 (점프로 넘기, 탄막 틈 읽기, 패링) | 공간·우회 (옆으로 비키기, 등 뒤, 거리 조절) |
| 약점 | 옆으로 비킬 수 없음 | 탄막·높이 거리감이 어려움 |

좌표: 로직은 지금처럼 바닥 (x, y) + 높이 z. **2D 시점은 y(깊이)를 무시**하고 x(좌우)·z(높이)만 본다.

## 2. 판정 투영

바닥 범위(부채꼴·원·직사각형)를 2D에서 쓸 때는 **x축 구간**으로 바꾼다 = 그 범위를 옆에서 봤을 때 차지하는 좌우 폭.

| 모양 | 2D 구간 |
|---|---|
| 원 (중심 cx, 반지름 r) | [cx − r, cx + r] |
| 부채꼴 | 호 끝점·중심의 x 최소~최대 (축 방향 포함) |
| 직사각형 | 네 꼭짓점 x 최소~최대 |

높이: 공격마다 높이 구간 [바닥, 위]를 가짐 (기본 [0, 플레이어 키]). 2D에서는 **x 구간 안 + 높이 구간 안**이면 맞음.
→ 낮게 쓸기(높이 0~20)는 2D에서 점프로 넘을 수 있음.

## 3. 전환

| 항목 | 값 `[추정, 플레이하며 조정]` |
|---|---|
| 게이지 최대 | 100 |
| 전환 비용 | 40 |
| 채우기 | 공격 적중 +8, 패링 성공 +25 |
| 무방비 | 0.3초 (이동·공격·회피 불가, 맞으면 그대로 피해) |
| 강제 전환 | 보스 패턴이 시점을 바꾸고 그 패턴이 끝날 때까지 **잠금** (게이지 소모 없음) |
| 2D → 3D | 깊이(y)는 2D로 들어갈 때의 값 그대로 |

## 4. 강제·유리 상황 (실험판 2개 + 후보)

| 상황 | 2D | 3D | 성격 |
|---|---|---|---|
| **칼날 벽** (실험판) | 경기장 좌우 전체·높이 전체 → 피할 곳 없음 | 깊이 방향으로 얇은 벽 → 옆으로 비키면 피함 | **3D 강제** (보스가 2D로 강제 전환한 뒤 쓰면 → 플레이어가 게이지로 탈출) |
| **탄막** (실험판) | 높이가 다른 탄들이 한 줄로 → 틈이 보임, 점프·숙이기 | 깊이까지 흩어져 거리감 어려움 | **2D 유리** (보스가 3D에서 쓰면 2D로 바꾸는 게 이득) |
| 분신 | 겹쳐서 하나로 보이고 진짜만 그림자 | 여러 명 | 2D 유리 (후보) |
| 등 뒤 약점 | 안 보임 | 돌아서 침 | 3D 강제 (후보) |
| 기둥 뒤 보스 | 깊이 무시 → 칠 수 있음 | 막힘 | 2D 강제 (후보) |

## 5. 학습 보스와의 연결

| 기록 | 보스 반응 |
|---|---|
| 시점별 머문 시간 | 내가 오래 머무는 시점에서 불리한 패턴을 더 고름 (실험판) |
| 전환 타이밍 | 내가 주로 바꾸는 순간(예: 큰 기술 준비 중)을 노림 (이후) |
| 시점별 사망 | 많이 죽은 시점으로 강제 전환 (이후) |

## 6. 실험판 범위

1. 판정 투영·점프·시점/게이지 로직 + 테스트
2. 카메라 전환(0.4초) + 도트 렌더링(낮은 해상도 + 제한 색)
3. 강제 상황 2개 (칼날 벽, 탄막)
4. 보스 반응 1개 (선호 시점)
5. HUD: 체력 바, 회복약, 게이지, 시점 표시

### 실험판에서 정한 것
- 칼날 벽은 **강제 전환하지 않음** — 2D에 있으면 피할 수 없으니 예고 중에 플레이어가 게이지로 3D로 탈출해야 함. 2D에 오래 머물수록 자주 나옴 (`viewBias: 2D ×4, 3D ×0.6`).
- 탄막은 **시련이 2D로 바꿔 줌** (1막의 정직한 가르침). 2막의 오염된 버전은 반대로 불리한 시점으로 강제하는 배신으로 쓸 수 있음.
- 되감기 기록에 시점 상태도 포함 (되감으면 시점·게이지·잠금도 돌아감). 체력·회복약도 패턴 시작 시점으로 돌아감.
