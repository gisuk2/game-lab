## 1. 한 줄

**쫓기는 해적선을 실시간(언제든 멈춤)으로 지휘해, 판타지 바다를 건너 목표에 닿는다. 배는 방으로 나뉘고, 마력을 어디에 줄지·선원을 어디에 보낼지가 매 순간의 결정이다.**

## 2. 원칙

1. **매 순간 작은 결정** — 일시정지하고 마력·선원·조준을 바꾸는 재미 `[원작]`
2. **위기는 연쇄된다** — 구멍 → 침수 → 펌프실 잠김 → 물이 더 참… `[원작][바다]`
3. **욕심과 안전 사이** — 더 탐색할지, 지금 도망칠지 (추격) `[원작]`
4. **판마다 다른 배** — 무기·사역마·선원·유물 조합으로 빌드가 달라짐 `[원작]`
5. **바다만의 상호작용** — 물과 불이 서로 영향을 주고, 배끼리 갈고리로 붙는다 `[새것]`

## 3. 한 판의 흐름

| 바다 (섹터) | 데모 3개 / 본편 8개 `[추정]`. 바다마다 성격(해군 해역, 해적 소굴, 안개 군도, 괴물 바다…) |
| 지도 | 섬·항구·바다 지점이 항로로 이어짐. **자유롭게 오감** `[원작]`. 한 번 이동 = **식량 1** `[바다]` |
| 칸 정보 | 기본은 안개 속 ❓. **망원경** 등급만큼 이웃 칸 종류가 보임(전투·상점·이벤트·보물·정예·위험) `[새것]` |

## 5. 배

### 5.1 구조
- 배는 **격자 방**들로 나뉘고 방끼리 **문**으로 이어짐 `[원작]`. 방 = 1×2, 2×2 칸 `[추정]`
- 방 하나에 시스템 하나 (없을 수도 있음). 선원은 칸 단위로 서 있음.

### 5.2 마력로와 시스템 `[바다]` (원작: 원자로·전력)
- **마력로**가 마력 칸 N개를 만듦 (시작 8 `[추정]`, 업그레이드로 늘림).
- 시스템마다 **등급**(최대 칸)이 있고, 마력을 칸 단위로 꽂아야 작동. 피해를 입으면 칸이 망가져 그만큼 못 씀 → 수리.

| 시스템 | 원작 | 하는 일 |
|---|---|---|
| 🛡 결계 | 방어막 | 마력 2칸당 결계 1겹. 한 겹이 피해 한 번을 막고 잠시 뒤 다시 참 |
| ⛵ 돛 | 엔진 | 회피율, 도망치기 충전 속도 |
| 💧 펌프 | 산소 | **침수된 물을 퍼냄** (§6.1). 꺼지면 물이 계속 참 |
| 💥 포갑판 | 무기 | 무기마다 필요 마력, 충전 시간 |
| ⚕ 의무실 | 의무실 | 안에 있는 선원 회복 |
| 🦜 사역마 둥지 | 드론 | 사역마(바닷새 정찰·수리 요정·공격 해파리…) 소환, 정수 소모 |
| 🪝 갈고리 | 순간이동기 | 적 배에 **갈고리를 걸고 선원을 승선**시킴 (§7.3) `[바다]` |
| 🌫 안개 장막 | 은폐 | 잠시 회피 크게 + 적 무기 충전 멈춤 |
| ☠ 저주 | 해킹 | 적 시스템 하나를 잠시 망가뜨림 |
| 🎵 세이렌의 노래 | 정신 조종 | 적 선원 하나를 잠시 우리 편으로 |

| 보조 시스템 (마력 X, 등급만) | 원작 | 하는 일 |
|---|---|---|
| ⚓ 조타실 | 조종석 | 사람이 있어야 회피가 생김. 등급 높으면 비어 있어도 일부 |
| 🔭 망원경 | 센서 | 적 배 안 보기, 지도 칸 정보 (§3) `[새것: 지도 연결]` |
| 🚪 문 | 문 | 문 튼튼함, 원격 개폐 |

## 6. 위험: 물·불·구멍 `[바다]`

### 6.1 침수 (원작 산소를 대신함)
- 방마다 **물 높이 0~100%**.
- **선체 구멍**이 뚫린 방은 매초 물이 참. 열린 문으로 이웃 방에 **흘러 퍼짐** (높은 쪽 → 낮은 쪽).
- 물 높이별: 30% 이상 = 선원 이동 느림 · 60% 이상 = 그 방 시스템 꺼짐 + 선원이 조금씩 다침 · 100% = 크게 다침
- **펌프**가 배 전체의 물을 조금씩 뺌 (등급만큼). 구멍을 수리해야 근본 해결.
- 원작의 "문 열어 산소 빼서 불 끄기"를 대신하는 우리 운영: **문을 열어 물을 불난 방으로 흘려보내 끄기** `[새것]`

### 6.2 화재 `[원작]`
- 칸 단위로 번지고 시스템을 망가뜨리고 선원을 다치게 함.
- **물이 30% 넘는 칸에서는 불이 못 붙고 꺼짐** `[새것]`
- **화약고**(포갑판 옆 특수 방)에 불이 닿으면 폭발 → 큰 피해 `[새것]`

### 6.3 구멍·시스템 피해 `[원작]`
- 맞으면: 시스템 칸 파손 + 확률로 화재 / 구멍 / 선원 부상.
- 선원이 방에 가서 수리 (기술이 높을수록 빠름).

## 7. 전투 `[원작]`

### 7.1 기본
- 화면 왼쪽 = 우리 배, 오른쪽 = 적 배 (적 배는 망원경이 없으면 시스템만 보이고 안은 안 보임).
- **언제든 일시정지** (스페이스바) → 마력·선원·조준을 바꾸고 다시 진행.
- 무기마다 **충전 시간**. 충전되면 **적 방을 골라** 발사 (자동 발사 켜기 가능).
- 명중 판정: 적 **회피율**로 빗나감 → 결계 겹이 있으면 한 겹 소모 → 없으면 피해.
- 이기는 법: 적 선체 0 / 적 선원 전멸(배 통째로 얻음, 보상 큼) / 도망치기(돛 충전).

### 7.2 무기 (첫 묶음 `[추정]`)

| 무기 | 원작 대응 | 특징 |
|---|---|---|
| 대포 (경·중) | 레이저 | 실탄 1~3발, 결계 1겹씩 벗김 |
| 쇠사슬탄 | 이온 | 피해 대신 **결계·돛을 잠시 마비**, 겹쳐 쌓임 |
| 박격포 | 미사일 | **결계 무시**, 화약 1 소모 |
| 화염탄 | 폭탄(화재) | 맞은 방에 큰 확률로 화재 |
| 작살 | 빔 | 방들을 잇는 선으로 그어 피해, 결계 1겹이라도 있으면 크게 약해짐 |
| 산탄 | 대공포 | 넓은 범위, 결계에 여러 번 부딪혀 벗김 |
| 저주 탄 `[새것]` | — | 맞은 방에 **물이 차오르게** (구멍 없이 침수) |

### 7.3 갈고리 승선 `[바다]` (원작: 순간이동기)
- 갈고리를 걸면 두 배가 **붙고**, 선원이 고른 적 방으로 넘어감 (등급 = 한 번에 보낼 인원).
- 붙어 있는 동안: 양쪽 회피 −, **적도 우리 배로 넘어올 수 있음** `[새것]`
- 갈고리 줄은 적이 끊을 수 있음 (작살·칼). 끊기면 넘어간 선원은 다음 갈고리 때까지 고립.

## 8. 선원 `[원작]` + 판타지 종족 `[바다]`

### 8.1 기본
- 선원을 방으로 보내면 그 시스템에 보너스(조타실=회피, 포갑판=충전 속도, 돛=회피…).
- 쓰면 기술이 오름 (시스템별 2단계 `[추정]`).
- 하는 일: 수리 · 불 끄기 · 물에서 버티기 · 백병전.
- 길 찾기: 격자 최단 경로, 문을 지나감.

### 8.2 종족 (데모 4종 `[추정]`)

| 종족 | 강점 | 약점 |
|---|---|---|
| 인간 | 기술이 빨리 오름 | 특별한 것 없음 |
| 어인 | **물속에서 다치지 않고, 물 찬 방에서 수리가 빠름** | 불에 약함, 마른 방에서 조금 느림 |
| 석인 (바위 정령) | 불에 강함, 체력 많음 | 느림, 물에 빠지면 매우 느림 |
| 고블린 기술자 | 수리 아주 빠름, 사역마 효율 + | 백병전 약함 |
| (나중) 유령 | 물·불 무관, 벽 하나 통과 | 체력 적음, 의무실로 회복 안 됨 |
| (나중) 세이렌 | 사기 +, 노래 시스템 강화 | 백병전 약함 |

## 9. 이벤트 `[원작]`
- 짧은 글 + 선택지 2~4개. 결과: 보상 / 함정 / 전투 / 선원·유물 획득 / 평판·사기 변화.
- **파란 선택지**: 특정 시스템·종족·유물·평판이 있으면 열리는 특별 선택지 (예: 어인 선원 → "물속으로 뛰어들어 살펴본다").
- 이벤트는 데이터(JSON)로 — 글은 전부 새로 씀. 데모 40개 `[추정]`.
- **스토리라인 이벤트**: 스토리라인마다 고유 이벤트 사슬 (지도 조각 → 다음 단서).

## 10. 항구와 성장 `[원작]`
- 상점: 무기·사역마·유물(패시브)·선원·시스템·식량·화약·정수, 선체 수리.
- 업그레이드: 마력로 칸, 시스템 등급 (금화).
- 유물 `[원작: 증강]`: 패시브 효과 (예: "물먹은 나침반: 안개에서도 이웃 칸 하나 보임").
- 평판에 따라 가격·물건이 달라짐 `[새것]` (해적 평판이 높으면 해군 항구 가격 ↑, 암시장 열림)

## 11. 스토리라인 (해적, 데모 1개 + 후보)

| 스토리라인 | 목표 | 쫓는 것 | 최종 보스 |
|---|---|---|---|
| ① 가라앉은 왕관 (데모) | 지도 조각 3개를 모아 바다에 가라앉은 왕관을 찾음 | 해군 함대 | 해군 기함 (3단계) |
| ② 배신자의 항로 (후보) | 나를 배신한 옛 동료 선장에게 복수 | 그의 현상금 사냥꾼들 | 옛 동료의 배 |
| ③ 유령 함대 (후보) | 저주받은 선원을 구하려 유령 해역 끝까지 | 유령 함대 (지나간 칸이 저주받음) | 유령 기함 |

- 하나를 깨면 다음 선장·배가 열림 `[원작: 함선 해금]`.

## 12. 원작에 없는 바다·판타지 상호작용 모음 `[새것]` (실험판마다 하나씩 시험)

1. 물로 불 끄기 / 화약고 폭발
2. 갈고리로 붙으면 양쪽 다 넘어올 수 있음 (적의 역승선)
3. 날씨: 폭풍 칸 = 돛 효과 ↑↓ 무작위, 번개가 결계를 벗김
4. 해류: 해류를 타면 식량 0으로 이동, 역류는 2
5. 바다 괴물 영역: 전투 중 괴물이 아무 배나 공격 (적에게도)
6. 사기와 반란
7. 평판 3세력과 칸·가격 변화
8. 저주 탄으로 구멍 없는 침수

## 13. 만드는 순서
