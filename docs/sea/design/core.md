## 1. 한 줄

**이순신과 판옥선이 판타지 이세계의 바다에 떨어진다. 엘프·드워프·수인 선원을 태우고, 같이 넘어온 왜 수군에 쫓기며, 조선으로 돌아가는 문을 찾아 바다를 건넌다.** 전투는 실시간(언제든 멈춤)이고, 배는 방으로 나뉜다.

## 2. 세계관과 톤

| 항목 | 내용 |
|---|---|
| 플레이어 | **플레이어 = 이순신** (지휘관의 눈). 이벤트에서 말하고 선택하는 건 이순신, 배 안에서 움직이고 싸우는 건 **장수와 이종족 선원들** — 원작에서 선장이 화면에 없고 승무원을 부리는 것과 같은 구조 |
| 시작 | 바다 위 큰 소용돌이에 휘말려 이세계로. 역사 속 정확한 시점은 따지지 않음 (깊은 고증은 하지 않음) |
| 목표 | 바다 끝 어딘가에 있다는 **귀환의 소용돌이**를 찾아 조선으로 돌아감 |
| 적 | **같이 넘어온 왜 수군**. 이세계에서 오크 해적·인간 용병 등과 손잡고 세력을 키움. 귀환의 문을 먼저 차지하려 함 |
| 판타지 강도 | **해적 전설 수준**: 크라켄, 세이렌, 폭풍의 바다, 유령 함대, 저주받은 보물. 종족은 서양식 판타지(엘프·드워프·수인·오크…) |
| 무기·배 | **조선 수군 고증**을 살림 (총통, 비격진천뢰, 신기전, 판옥선, 거북선). 수치·규칙은 게임에 맞게 각색 |
| 재미 포인트 | 이순신이 **옛 사람의 눈으로** 이종족을 보고 하는 말 (§10.2). 존경을 담되 문화 충돌로 웃기게 |
| 적 묘사 | 역사 속 적으로 담백하게. 비하·조롱 없이 "강하고 영리한 적" |

## 3. 원칙

1. **매 순간 작은 결정** — 일시정지하고 마력·선원·조준을 바꾸는 재미 `[원작]`
2. **위기는 연쇄된다** — 구멍 → 침수 → 배수실 잠김 → 물이 더 참 `[원작][바다]`
3. **욕심과 안전 사이** — 더 탐색할지, 지금 도망칠지 (추격) `[원작]`
4. **판마다 다른 배** — 총통·갑판 장비·선원·부품 조합으로 빌드가 달라짐 `[원작]`
5. **바다만의 상호작용** — 물과 불, 등선 육박전, 날씨 `[새것]`
6. **이름은 엄격히, 쓰임새는 자유롭게** — 무기·배·인물·진법의 **이름과 실제로 있었는지**는 반드시 출처가 있어야 함 (없는 이름을 지어내지 않음). 그 무기를 어떻게 쓰고, 장수가 어떻게 싸우고, 진법이 무슨 효과를 내는지는 **이세계 설정이라 자유**. 게임 속 "역사 한 줄"은 출처 있는 사실만 `[고증]`

## 6. 배

### 6.1 배 종류 `[고증][각색]`

| 배 | 고증 | 게임 |
|---|---|---|
| **판옥선** (시작 배) | 조선 수군 주력함. 갑판을 2층으로 꾸며 **노 젓는 군사와 싸우는 군사가 층을 나눠** 일함 | 아래층 = 격군·화약고·선창, 위층 = 포갑판·장대(지휘). 균형형 |

| (후보) 이세계 배 | 엘프 쾌속선, 드워프 철갑선 | 해금 배 |

### 6.2 마력로와 방 (2026-11-19 확정)
- **설정: 이 배는 마력으로 움직인다.** 이세계에 떨어진 판옥선 밑바닥에 **마력로**가 박혀 있고, 돛·격군·결계·총통까지 모두 그 마력을 나눠 씀 `[새것]`.
- **마력로는 방이 아니라 화면 아래 막대** (원작 리액터와 같음) `[원작]`. 시작 8칸 `[추정]`. 시스템마다 등급(최대 칸)이 있고 칸 단위로 마력을 꽂음.
- **방 이름 원칙**: 고증보다 **한눈에 알아보기**가 우선. 조선 말·쉬운 말·판타지 말을 섞어 씀. 방 이름은 실존 무기·인물 이름이 아니라서 자유 (§3 원칙 6).
- 한 판에서 보는 방은 10개 안팎 (원작도 시작 배는 시스템 방 8개 + 빈 방, 나머지는 상점에서 삼) `[기억 기반]`.

## 7. 위험: 물·불·구멍 `[바다]`

### 7.1 침수 (원작 산소를 대신함)
- 방마다 물 높이 0~100%. 구멍 난 방은 물이 차고, 열린 문으로 **흘러 퍼짐**.
- 30% 이상: 이동 느림 · 60% 이상: 그 방 시스템 꺼짐, 선원 조금씩 다침 · 100%: 크게 다침
- 배수실이 배 전체의 물을 조금씩 뺌. 구멍을 수리해야 근본 해결.
- **문을 열어 물을 불난 방으로 흘려보내 끄기** `[새것]`

### 7.2 화재 `[원작]`
- 칸 단위로 번지고 시스템·선원 피해. **물 30% 넘는 칸에선 불이 꺼짐** `[새것]`
- **화약고**에 불이 닿으면 폭발 `[새것]`

### 7.3 구멍·시스템 피해 `[원작]`
- 맞으면: 시스템 칸 파손 + 확률로 화재 / 구멍 / 선원 부상. 선원이 가서 수리.

## 8. 전투

### 8.1 기본 `[원작]`
- 왼쪽 = 우리 배, 오른쪽 = 적 배. 언제든 일시정지(스페이스바).
- 무기마다 충전 → 적 방을 골라 발사. 명중: 회피 → 결계 한 겹 → 피해.
- 승리: 적 선체 0 / 적 선원 전멸(배 나포) / 도망치기.
- **거리**: §8.5 · **진법(전술)**: §8.6

### 8.2 총통과 화기 `[고증][각색]`

| 무기 | 고증 | 게임 (장점 / 단점) |
|---|---|---|
| **천자총통** | 천·지·현·황자총통은 천자문 첫 네 글자로 이름 붙인 크기 순서 — 천자가 가장 큼. 판옥선·거북선의 대형 함포로 길이 3m의 **대장군전**을 쏴 적선에 큰 구멍을 냄, 한 번에 화약 30냥 | 한 발 피해 아주 큼 + **큰 구멍(침수)** / 충전 아주 느림, 마력 많이 씀 |
| **지자총통** | 두 번째 크기 | 피해 큼, 충전 느림 |
| **현자총통** | 세 번째 크기 | 균형형 (피해·충전 보통) |
| **황자총통** | 가장 작음 | 충전 빠름, 결계 벗기기 좋음 / 피해 약함 |
| **비격진천뢰** | 선조 때 이장손이 만든 **폭발 시간을 조정하는 시한폭탄형 포탄**. 완구로 쏘며 사정거리 약 300보, 포열이 없어 정확도 낮음. 터지면 화염과 쇳조각이 퍼짐 | **결계 무시**, 방에 떨어진 뒤 **몇 초 뒤 폭발**(화재 + 선원 피해) → 그 사이 선원을 대피시킬 수 있음 / 화약 소모, 빗나감 많음 |
| **신기전 (화차·신기전기)** | 세종 때부터 쓴 로켓 화살. 문종 화차의 발사틀에 중신기전 100발을 꽂아 한꺼번에·잇따라 발사 | **여러 발 일제 사격** → 결계를 여러 번 두드려 벗김 / 한 발 피해 약함 |
| **철환 다발 장전** (산탄) | 조선 수군은 총통에 **여러 발의 철환을 장전해 쏘는 다발식 장방법**을 썼다. (이름 "조란환"은 `[확인 필요]`) | 선원 살상, 넓은 범위 / 선체 피해 약함 |
| **화전** (불화살) | 불을 붙인 화살 `[확인 필요: 세부]` | 화재 확률 큼 / 피해 약함 |
| (적 전용) **조총** | 왜군의 화승총 `[확인 필요: 세부]` | 등선한 왜군이 선원을 원거리에서 쏨 |

**고증 바로잡기 (2026-11-19, 연구 논문 확인)**
- 임진왜란 때 조선 수군은 대체로 **폭발하지 않는 고체탄**을 주로 썼다 → 총통 피해는 **관통·파손(구멍)** 위주, 폭발·화재는 비격진천뢰·화전 같은 특수 화기만.
- 조선 수군이 **들이받는 충돌 전술**을 적극 썼다는 사료 근거는 없다 → 충돌 공격은 넣지 않음.
- 조선 수군이 **등선 백병전**에 적극적이었다는 사료 근거도 없다 → 등선은 이세계 종족 선원이 하는 `[각색]`, 왜 수군 쪽 장기로 둠.
- 신기전은 임진왜란 때에도 쓴 기록이 있음. 비격진천뢰는 1593년 웅천 수륙합공 때 수군이 쏜 기록(이순신 장계)이 있음.

`[확인 필요]` 표시는 설계 확정 전에 출처를 더 찾을 것. 총통별 정확한 사거리·탄종은 사료마다 달라 **게임 수치에는 쓰지 않음** (크기 순서와 정체성만 가져옴).

### 8.5 거리 — 조우할 때 확률로 정해짐 (2026-11-19 확정) `[새것]`

**배경 (연구)**: 조선 수군 총통은 사거리가 조총보다 길어 넓은 바다에서 싸우는 것이 유리했다는 연구가 있음 → **우리 = 멀리서 포격 / 왜 수군 = 붙어서 조총·등선**.

- 거리 **3단계**: 원거리 · 중거리 · 근접. **조우하는 순간 정해지고 그 전투 내내 고정** (전투 중에 거리를 조작하지 않음).
- **보스전**: 페이즈마다 거리가 정해져 있음 (예: 1페이즈 원거리 → 2페이즈 중거리 → 3페이즈 근접·등선 방어).

| 거리 | 우리에게 | 적(왜 수군)에게 |
|---|---|---|
| 원거리 | 천자·지자총통 강함, 비격진천뢰 가능 | 조총 거의 안 닿음 |
| 중거리 | 현자·황자총통, 신기전 | 조총 사격 |
| 근접 | 철환 다발(산탄) 강함, 대형 총통 명중 − | 등선 가능, 조총 최대 |

**정찰 판정 → 성공하면 내가 거리를 고름** `[추정]`

1. 조우하는 순간 **정찰 판정**을 굴림.
2. **성공** → 플레이어가 원거리·중거리·근접 중 **원하는 거리를 고름** (근접 좋아하면 근접으로!).
3. **실패** → 거리는 무작위 (적이 좋아하는 거리 쪽으로 조금 기움: 왜 수군·오크 해적 = 근접, 인간 용병 = 중거리).

| 정찰 성공률을 올리는 것 | 내리는 것 (정찰 디버프) |
|---|---|
| 사후선 (갑판 장비) | 짙은 안개 칸 |
| 망원경 등급 | 폭풍 칸 (밤·악천후) |
| 엘프 선원·어영담 같은 정찰 특기 | 기습 이벤트 (적이 먼저 발견) |
| 조우 직전 이벤트에서 이순신의 판단 | 적의 연막·은신 |
