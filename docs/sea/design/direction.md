## 0. 한 줄

**FTL의 전투 손맛은 그대로, 판을 짜는 재미(컨셉 빌드·지도·보상)는 슬더스처럼.**

| 살릴 것 (FTL) | 고칠 것 |
|---|---|
| 실시간 + 일시정지 전투, 마력 배분, 선원 운영 | ① 컨셉 플레이가 적음 |
| 적당히 어렵고 컨트롤이 필요한 곳에 쓰이는 전투 밸런스 | ② 추격 압박이 "도망치며 파밍"이라는 한 가지 정답만 줌 |
| 이벤트 글과 선택지 | ③ 후반 상점·영입이 정해진 듯함 |
| | ④ 보스·스토리가 밋밋함 |
| | ⑤ (걱정) 이 밸런스를 우리가 맞출 수 있는가 |

## 1. 컨셉 플레이 → "판을 바꾸는 유물"을 중심에

컨셉 빌드는 무기 수를 늘린다고 생기지 않는다. **규칙을 바꾸는 아이템**이 있어야 생긴다 (슬더스 유물, 발라트로 조커).

- **유물**(장신구): 수치를 조금 올리는 것보다 "이걸 얻으면 이렇게 놀 수 있다"는 **빌드 엔진**을 우선.
- 엔진 유물은 희귀하게, 그 빌드를 받쳐 주는 무기·병서·장수는 흔하게 → 엔진을 만나면 방향을 틀 수 있게.

| 컨셉 | 엮이는 것 | 엔진 유물 예 (이름·효과 미정) |
|---|---|---|
| 초원거리 포격선 | 천자·지자, 망원경, 학익진 | 원거리에서 첫 일제 사격 피해 2배 |
| 백병전 올인 | 등선판, 오크·수인, 장사진·예진 | 적 선원을 쓰러뜨릴 때마다 사기 +, 나포 보상 2배 |
| 퇴각 스피드런 | 격군, 사후선, 연막 | 전투 없이 도망쳐도 보상 일부 |
| 함정선 | 빗장실, 화약고, 원진 | 등선한 적이 화약고 방에 들어오면 폭발 |
| 버틸수록 강해짐 | 결계, 일자진, 수리 | 맞을 때마다 결계 재충전 빨라짐 |

전체 목록: **[유물 50개](relics.md)** (2026-11-19, 10개 구현).

유물 이름은 **이세계 물건이면 자유**, 실존 물건 이름을 쓸 땐 고증 원칙(이름·실존은 엄격히)을 따른다.

## 2. 긴장감 → 슬더스식 지도 + 압박을 "선택"으로

- **지도**: 슬더스식 **갈림길 지도**. 전투·정예·이벤트·항구·보물 칸이 보이고 경로를 미리 짬. 망원경·사후선은 칸 안의 **세부**(적 종류·보상)를 보여 줌.
- **왜 수군 대함대 추격 = 위협 수치** (시간 벽이 아님): 이동·지체할수록 오름 → 적이 세지고 이벤트가 나빠짐. **낮추는 방법을 여러 개**: 안개 칸에 숨기, 미끼 배, 추격 선봉과 싸워 큰 보상, 특정 이벤트.
- **군량**: 이동마다 −1. 약탈·낚시·어인 선원·이벤트로 채움 → 압박은 있지만 대처법은 내가 고름.

## 3. 경제 → 전투마다 보상, 상점은 보조

- **전투가 끝날 때마다 보상** (약탈·포로·노획이라 개연성도 있음):
  - 고정: 금화·자재 (적 종류·나포 여부에 따라)
  - 선택: **셋 중 하나 고르기 또는 건너뛰기** — 무기 / 유물 / 선원·장수 / 병서 중에서
- **항구**는 보조: 수리, 방 증축·시스템 등급, 특정 물건 사기, 선원 모집.
- **잡다함 막기 — 칸마다 역할 하나**

| 칸 | 역할 | 한계 |
|---|---|---|
| 무기 | 포갑판 슬롯에 담 | 슬롯 수 |
| 유물 | 빌드 엔진 (패시브) | 적게 나옴 |
| 병서 | 진법 (§8.6) | 한 번에 하나 사용 |
| 선원·장수 | 사람 | 배 정원 |
| 배 | 수리·증축·등급 (항구) | 금화 |

- **등급**: 일반 → 고급 → 희귀. 희귀 무기는 **수식어**로 ("개량 지자총통", "드워프 강철 황자총통", "엘프 조준 현자총통"). 실존하지 않는 "명품 총통" 이름은 만들지 않음 (고증 원칙).
- **운 조절**: 재굴림 토큰, 시작 유물 고르기 등 확률을 내가 다룰 장치 하나 이상.
- 가챠처럼 안 되게: 늘 **고르는 행위**가 있고, 건너뛰기도 선택지.

## 4. 스토리·보스

- **컷씬**: 바다마다 짧은 장면 하나 정도. 이순신의 눈 대사로 코미디, 역사 한 줄은 끌 수 있게. 완급 조절이 핵심 (§3 원칙: 절대 딥하게 가지 않음).
- **보스 후보**

| 후보 | 근거 | 메모 |
|---|---|---|
| 아타케부네 (철판) | 실존 일본 대형 군선 (core §6.1.1) | 마지막 왜 수군 대장선 |
| 무적함대 | 1588 스페인 함대, 실존 | 같이 이세계로 넘어온 설정 — 출처 확인 후 |
| 유령선 | 공유 전설 (플라잉 더치맨 등) | 이세계 바다 보스 |
| 우리만의 해적선 | 창작 | "그런 느낌"의 해적 보스 |
| ~~고잉메리호~~ | **원피스 저작권 디자인** | ❌ 판매 게임에 못 씀 |

## 5. 전투 밸런스 — AI 시뮬로 되는 것과 안 되는 것

**되는 것** (봇 수천 판):
- 조합 하나가 너무 센지, 전투가 너무 길거나 짧은지, 거리가 판을 정하는지 → 이미 하고 있음 ([개발 일지](../devlog/2026-11-19-sea1-battle.md))
- **"컨트롤을 쉬면 바로 지는가"** → **봇 실력 3단계**로 잼 (`SKILL` in `bot.ts`)

| 봇 | 하는 일 | 목표 | SEA-1 결과 (200판) |
|---|---|---|---|
| 손 놓음 | 처음에 마력·조준만 | 반드시 짐 | 1~4% ✅ |
| 초보 | 3초마다 생각, 일제 사격 모름, 의원실 안 감 | 50~60% | 38~43% (조금 어려움) |
| 숙련 | 0.5초마다, 일제 사격, 수리·치료 | 85% 안팎 | 57~87% |

**안 되는 것**: 재미·손맛·편의성 → 짧게 만들고, 직접 해 보고, 고치는 순서로.

| 묶음 | 내용 |
|---|---|
| 지도 | 슬더스식 갈림길 지도 15~20칸, 칸 종류(전투·정예·이벤트·항구·보물), 망원경·사후선으로 칸 세부 |
| 압박 | 위협 수치(대함대 추격), 군량, 낮추는 방법 2~3개 |

| 이벤트 | 10~20개 (이순신의 눈 대사) |
