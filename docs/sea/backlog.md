## 추후 다듬기 🔧

| # | 항목 | 메모 |
|---|---|---|
| P1 | 시스템 이름 (마력로·결계·저주 등) | 사용자: "추후 계속 수정". 지금은 마력로·저주 유지 |
| P2 | 네임드 장수가 쓰러졌을 때 | 지금은 **하드: 그 판에서 잃음**. 너무 아프면 "중상 이탈(다음 판에 다시 만남)" 검토 |
| P3 | 역사 한 줄 카드 | 1~2줄 유지, 깊게 들어가지 않기. 설정에서 끄기 옵션 |
| P4 | 이순신 대사·만남 대사 | 지금은 임시. 톤: 존경 + 문화 충돌의 웃음 |
| P5 | 총통·화기 수치 | 전부 [추정] → 봇 대결 시뮬레이터와 직접 플레이로 |
| P6 | 고증 `[확인 필요]` 항목 | 조란환·화전·조총 세부, 총통별 탄종 — 출처 더 찾기 |
| P7 | 적(왜 수군) 묘사 | 비하 없이 강하고 영리한 적. 대사·장수 설계 때 다시 점검 |
