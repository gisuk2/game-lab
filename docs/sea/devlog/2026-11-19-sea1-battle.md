# 2026-11-19 전투 한 판 실험판 (SEA-1)

`games/sea/` — 판옥선 1척 vs 왜선 1척. 실시간 + 일시정지, 마우스로 지휘. 그림은 도형·아이콘만.
설계: [핵심 설계](../design/core.md) §6.2(방) · §7(물·불·구멍) · §8(전투·거리·진법)

## 정한 것 (이번 대화)

| 항목 | 결정 |
|---|---|
| 화면 | **배를 옆에서 자른 단면** (위층 = 싸우는 곳, 아래층 = 일하는 곳). 선원은 옆으로 걷고 사다리로 오르내림 |
| 물·불 | **물은 아래로 떨어지고 아래층부터 잠김**, 불은 사다리를 타고 **위로 잘 번짐** — 원작에 없는 우리 규칙 |
| 적 배 | 일반 적은 **왜선**으로 통일. 보스만 나중에 실제 배 이름(아타케부네 등) |
| 마력로 | 방이 아니라 화면 아래 막대 (원작 리액터처럼) |

## 봇 대결 결과 (1000판씩, 수치 전부 `[추정]`)

**판옥선끼리 — 총통 조합 (중거리)**: 왼쪽 배의 승률

| 왼쪽 \ 오른쪽 | 지자+황자 | 현자+황자 | 천자 | 황자×3 |
|---|---|---|---|---|
| 지자+황자 | 51% | 80% | 79% | 71% |
| 현자+황자 | 20% | 50% | 63% | 40% |
| 천자 | 21% | 37% | 48% | 28% |
| 황자×3 | 25% | 60% | 72% | 49% |

**판옥선 vs 왜선 — 거리 × 진법**

| 거리 | 진법 없음 | 학익진 | 장사진 | 평균 전투 시간 |
|---|---|---|---|---|
| 원거리 | 100% | 100% | 100% | 2~3분 |
| 중거리 | 80% | 91% | 87% | 2~2.5분 |
| 근접 | 22% | 40% | 32% | 2.5분 |

**정찰 판정을 거친 실제 조우 (성공하면 원거리, 학익진)**: 망원경 0등급 73% · 1등급 80% · 2등급 85%

### 수치를 고친 과정
1. 처음엔 원거리에서 끝나지 않는 판(10분 무승부)이 많았음 → 왜선 선체 22 → 12, 봇 일제 사격 순서 수정(가벼운 총통이 먼저 결계를 벗김)
2. 천자총통 혼자는 결계 한 겹에 매번 막혀 0% → **결계 한 겹을 뚫고 피해 −1**
3. 황자×3이 모든 조합을 이김(92~100%) → 황자 충전 9 → 13초, 지자 16 → 12초
4. 직접 해 보니 한 발씩 쏘면 결계에 다 막혀 아무것도 못 함 → **일제 사격** 체크(기본 켬)

## 검증
- 테스트 310개 통과 (기존 279 + 새 31), `tsc` 통과
- 봇 1000판 × 15가지: 무승부(10분 넘김) 0판
- 헤드리스 브라우저 자동 플레이(실제 클릭): 조우 창 → 거리 고르기 → 총통 조준 → 진법 → 원거리 72초 승리 / 아무것도 안 하면 패배. 침수·화재 화면, 승패 창, "다음 왜선" 확인. 콘솔 에러 없음
- **확인 못 한 것**: 실제 Vite 빌드(`npm run dev`)는 PC에서 확인 필요

## 알게 된 것 / 다음
- 원거리는 너무 쉬움(100%) → 원거리용 왜선 무기(대포 위주 왜선)가 필요 → 백로그 A12
- 근접은 22~40%: "근접은 왜 수군 유리"가 잘 드러남. 철환 다발(산탄)·등선이 들어오면 다시 봄
- 장사진의 백병전 효과는 등선이 없어서 아직 의미 없음
- 방 배치 시안 비교(D4)는 이 화면 위에서 할 것

## 추가: 선원 조작이 안 보이던 문제 (같은 날)

| 요청 | 구현 |
|---|---|
| 선원 눌러서 수리하는 게 안 보임 | 고른 선원 깜빡이는 테두리 + "갈 방을 클릭" 안내, 드래그로 여러 명 고르기, 마우스 올린 방 표시 |
| 뭘 하는지 안 보임 | 머리 위 아이콘 🧯 불 끄기 · 🪵 구멍 막기 · 🔧 수리 · ⭐ 자리 지킴(보너스) · 💚 치료, 방 아래 진행 막대, 방 설명 실시간 갱신 |
| 방에 선원이 있으면 뭐가 좋은지 없음 | 방 설명에 "막동: 자리를 지킴 → 총통 충전 +10%", 빈 방엔 "선원이 서 있으면: …", 장대가 비면 "⚠ 장대가 비었음 — 회피 0" |
| 선원 피가 너무 쉽게 닮 | 조총 한 발 15 → 8, 총통 선원 피해 −20%쯤, 불 초당 5 → 3, 물 2·6 → 1.5·4. 봇 300판: 한 판에 쓰러지는 선원 0명 (근접 승률 43%) |
| 피 닳으면? | 원작처럼 직접 의원실로 보냄. 30% 아래면 ❗ + 로그 경고, **M 키 / ⚕ 버튼** = 고른 선원(없으면 피 70% 아래)을 의원실로 |

검증: 테스트 310개, 헤드리스로 드래그 선택·아이콘·M 키 확인.

## 추가: 위에서 본 평면으로 전환 + 마력 자동 복원 (같은 날)

옆 단면은 방이 층마다 한 줄로 늘어서서 방 구성이 단순해짐 → **원작처럼 위에서 본 평면**으로 바꿈 (core §6.2).

| 항목 | 내용 |
|---|---|
| 방·문 | 칸 단위 사각형(x, y, w, h). 변을 맞댄 방끼리 문 하나씩 자동. 판옥선 7×4칸, 방 10개, 문 17개. 사다리 없앰 |
| 좌현·우현 | 포갑판 둘(좌현 2칸 = 지자, 우현 1칸 = 황자). 한쪽이 망가지면 그쪽 총통만 멈춤 |
| 물 | 열린 문으로 퍼짐(원작 산소처럼). **바깥 벽 방은 구멍 나면 빨리 참**(0.08), 안쪽 방은 느림(0.03). **배수구**(바깥 문 3개)를 열면 바다로 빠짐, 대신 연 방에 구멍 나면 ×1.5 |
| 마력 자동 복원 | 시스템마다 원한 마력(want)을 기억 → 고치거나 물이 빠지면 마력로가 남는 만큼 자동으로 다시 꽂음. 총통도 다시 켜지고 조준 유지. 패널에 "⏳ 고치면 다시 켜짐" |
| 조준 | 원작은 한 번 쏘면 풀리고 자동 사격을 켜야 계속 쏨 [기억 기반]. 우리는 늘 자동 사격(전투마다 한 번 조준). **숫자키 1·2**로 총통 고르기 |
| 왜선 | 5×2칸 평면, 방 6개 |

**봇 300판 (판옥선 vs 왜선)**: 원거리 100% · 중거리 70~87% · 근접 21~40% · 평균 2.5~3분 · 쓰러지는 선원 0명. 근접이 11%까지 떨어져서 조총 근접 명중 0.9 → 0.85.
판옥선끼리 총통 조합: 지자+황자 70~80%로 가장 셈, 나머지는 40~60%.

검증: 테스트 315개(sea 36), tsc, 헤드리스로 숫자키 조준·자동 복원 표시·한 판 확인.

## 추가: 무기 거리 특화 — 거리는 벌칙 없이 보너스만 (같은 날)

문제: 시작 총통(지자 1발 + 황자 1발)이 결계 1겹을 일제 사격 없이는 못 뚫음. 거리는 원거리 100% · 근접 21%로 판을 정해 버림.

| 바꾼 것 | 내용 |
|---|---|
| 명중률 | 거리와 상관없이 같음 (총통 0.9, 조총 0.8, 불화살·왜 대포 0.85) |
| 특화 거리 | 무기마다 하나. 그 거리에서만 보너스 (`spec`) |
| 천자 | 원거리: 결계 2겹까지 뚫음 (기본 1겹), 충전 18 → 15초 |
| 지자 | 원거리: 큰 구멍 (물 2배, 막으면 풀림) |
| 현자 | 중거리: 3발 |
| 황자 | **기본 2발**(충전 14초), 근접: 충전 ×1.35 + 장대·격군실을 쏘면 고장 +1 |
| 조총 | 근접: 4발 + 선원 피해 1.5배 |
| 불화살 | 원거리: 불 2배 (멀리서 불화살 비) |
| 왜 대포 | 원거리: 구멍 확률 ↑ (아직 왜선에 안 달림) |
| 왜선 | 선체 12 → 15 |
| 화면 | 조우 창에 거리마다 "✨ 우리 / ⚠ 왜선" 켜지는 보너스, 총통 카드에 "✨ 특화 켜짐", 마우스를 올리면 특화 설명 |
| 봇 | 결계가 꺼졌을 때 방 조건 특화(황자 → 격군실)를 노림 |

**봇 300판 (판옥선 지자+황자 vs 왜선, 진법 없음)**

| | 원거리 | 중거리 | 근접 |
|---|---|---|---|
| 일제 사격 켬 | 86% | 80% | 56% |
| 일제 사격 끔 | 62% | 59% | 54% |

- 전: 원거리 100% · 근접 21% → 일제 사격 없이도 50~60%로 싸울 수 있고, 거리 차이는 일제 사격을 쓸 때 30%p, 안 쓸 때 8%p.
- 평균 2~3분, 쓰러지는 선원 0명.
- **남은 문제**: 판옥선끼리 조합 비교에서 **황자×3이 가장 셈**(55~100%), 천자 혼자는 약함(9~53%). 상점이 생기면 가격·한 방에 같은 총통 제한 등으로 조절 → 백로그 P8.

검증: 테스트 321개(sea 42: 특화 6개 추가, "어느 거리도 판을 정하지 않음 40~95%" 테스트), tsc, 헤드리스로 조우 창·✨ 표시 확인.
