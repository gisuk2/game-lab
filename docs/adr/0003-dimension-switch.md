# ADR 0003: 2D·3D 시점 전환을 핵심 전투로, 다크 판타지로 방향 전환

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-11 |
| 상태 | **채택 (실험 단계)** — 실험판에서 재미가 확인되면 확정, 아니면 3D 소울류(ADR 0002)로 되돌림 |
| 대체 | ADR 0002의 "3D만" 결정을 확장 (3D 코드는 그대로 씀) |

## 배경

- 블라스퍼머스식 2D 횡스크롤 전투(정밀·타이밍)를 원함. 동시에 지금의 3D 소울류 전투(공간·우회)도 살리고 싶음.
- "둘 중 하나"가 아니라 **하나의 세계를 두 시점으로** 보면, 같은 공격이 시점에 따라 쉬워지거나 불가능해짐 → 시점을 바꿔야만 깨는 상황이 생김.
- 분위기는 현실적이고 암울한 다크 판타지 (웹소설 「튜토리얼이 너무 어렵다」 초반 분위기 참고 — 분위기만, 인물·용어·설정은 가져오지 않음).

## 결정

| 항목 | 결정 |
|---|---|
| 핵심 규칙 | **2D = 정밀·타이밍, 3D = 공간·우회** |
| 전환 주체 | **둘 다**: 보스 패턴이 강제로 바꾸고(잠금), 플레이어도 게이지를 써서 바꿈 |
| 전환 자원 | **게이지**: 공격 적중·패링 성공으로 차고, 전환할 때 소모 |
| 2D의 깊이 | **투영**: 깊이가 전부 한 줄로 겹침 (판정도 깊이 무시) |
| 전환 순간 | **무방비 0.3초** (무적 아님 → 회피로 남용 불가, 보스가 노리는 재료) |
| 조작 | 두 시점에서 같은 키: Space 점프, Shift 구르기, 좌클릭 공격, 우클릭 패링, E 시점 전환 |
| 체력 | 한 방 사망 → **체력 바 + 회복약** |
| 그림 | 2D 도트 스프라이트 대신 **3D 모델을 낮은 해상도 + 제한 색으로 그려 도트처럼** → 그림 한 벌로 두 시점 |
| 세계관 | SF(로봇·회사) → 다크 판타지(시련·안내자·수문장). 기능은 그대로 ([스토리 v0.4](../boss/design/story.md)) |

## 근거

| 근거 | 내용 |
|---|---|
| 로직 재사용 | 지금 로직은 바닥(x, y) + 높이(z) = 사실상 3D. 2D 시점은 "깊이(y)를 무시하고 옆에서 보는 것" → 판정 로직을 둘로 나눌 필요 없음 `[추정 → 실험판에서 확인]` |
| 학습 보스와 궁합 | 선호 시점·전환 타이밍·시점별 사망을 학습 → "내가 편한 시점에서 불리한 패턴" |
| 그림 비용 | 도트 스프라이트는 3D로 돌릴 수 없음 → 3D를 도트처럼 그리면 한 벌로 해결 |

## 위험과 대응

| 위험 | 대응 |
|---|---|
| 두 가지 손맛을 모두 다듬어야 함 | 실험판은 보스 1명, 강제 상황 2개로 재미부터 확인 |
| 전환이 너무 잦으면 어지러움 | 게이지 비용 + 무방비 0.3초 + 강제 전환은 잠금 |
| 조작 혼동 (2D 좌우 / 3D WASD) | 키를 같게, 2D에서는 W/S가 깊이 대신 아무것도 안 함 |
| 3D 도트 렌더링의 품질 | 실험판에서 스크린샷으로 확인, 부족하면 최종 그림 방식 다시 결정 |
