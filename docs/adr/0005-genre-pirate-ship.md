# ADR 0005: 새 게임 — FTL식 실시간 함선 운영 로그라이크, 판타지 바다의 해적선

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-18 |
| 상태 | **채택 (설계 단계)** — 핵심 설계 문서 초안 작성, 전투 한 판 실험판으로 재미 확인 예정 |
| 대체 | ADR 0004(게으른 영주)를 **동결** |
| 관련 | [핵심 설계](../sea/design/core.md) · [아이디어 노트 G6](../ideas/idea-notes.md) |

## 배경

- 사용자가 FTL: Faster Than Light를 거의 그대로 따라 하면서 몇 가지를 바꾼 게임을 만들고 싶어 함.
- 영주 게임은 화면·경제·구역 안 장면까지 실험판이 나왔지만, 새 게임으로 방향을 바꾸기로 함 (저장소는 `game-lab`으로 이름을 바꿔 여러 게임을 모으는 실험실로).
- 지금까지 확인된 강점: **순수 로직 + 테스트 + 전략 봇**으로 규칙을 빠르고 정확하게 만들 수 있음. 약점: **그림** (임시 도트 수준).

## 결정

| 항목 | 결정 |
|---|---|
| 장르 | 실시간 + 언제든 일시정지하는 **함선 운영 로그라이크** (FTL의 규칙과 한 판 흐름을 따름) |
| 배경 | **판타지가 섞인 바다**. 우주선 → 해적선, 산소 → **침수**, 순간이동 → **갈고리 승선**, 원자로 → **마력로** |
| 주인공 | **해적** (다른 진영·선장은 나중에 스토리라인으로 추가) |
| 그대로 가져갈 것 | 한 판 흐름, 실시간+일시정지 전투, 승무원, 이벤트, 상점과 성장 |
| 바꿀 것 | 이야기와 목표(**스토리라인 여러 개**), 우주 → 바다 |
| 더할 것 | 자원(식량·사기·평판·보물 지도 조각), 지도는 FTL식 + 칸 정보를 반쯤 보여 주기(망원경) |
| 1차 목표 | 3단계 데모판 (3개 바다 + 최종 보스, 30~40분) — 그 전에 **전투 한 판**으로 재미 확인 |

## 근거

| 근거 | 내용 |
|---|---|
| 강점 활용 | 전력 배분·피해·침수 확산·무기 충전 = 계산 위주 → 테스트·봇으로 검증하기 좋음 |
| 그림 부담 | 배 안은 **격자 방·문·아이콘** 위주라 코드로 그리기 쉬움. 배 외형·바다·초상화는 CC0 에셋 팩·AI 생성기로 |
| 검증된 재미 | 원작이 이미 증명한 루프. 우리가 할 일은 바다·판타지로 **새 상호작용**(침수↔화재, 승선, 날씨)을 더하는 것 |
| 저작권 | 규칙·구조는 따르되 이름·그림·이벤트 글·함선 디자인·음악은 새로 만듦 |

## 기존 것 처리

| 대상 | 처리 |
|---|---|
| `games/estate` (게으른 영주) | **동결** (지우지 않음, 테스트 계속 통과 유지). 경제 v3·조합 시너지 초안은 [economy.md §9](../estate/design/economy.md)에 남김 |
| `games/boss` | 동결 그대로 |
| 문서 체계·테스트·전략 봇 방식 | 그대로 |
| 기술 | TypeScript + Vite + Vitest, 화면은 Canvas/DOM (영주 게임과 같은 방식) — 필요하면 그때 엔진 검토 |

## 위험

| 위험 | 대응 |
|---|---|
| "FTL 그대로"라 새로움이 없음 | 바다·판타지만의 상호작용을 설계 문서 §10에 모아 두고 실험판마다 하나씩 넣어 봄 |
| 실시간 전투의 손맛·밸런스 | 순수 로직 시뮬레이터 + 봇(같은 배끼리 1000판)으로 1차 조정, 이후 직접 플레이 피드백 |
| 승무원 길 찾기·자동 행동이 복잡 | 처음엔 격자 최단 경로 + 단순 규칙, 실험판에서 점점 다듬음 |
| 그림 | 실험판은 임시 그림, 에셋은 출처·라이선스를 `ASSETS.md`에 기록 |
