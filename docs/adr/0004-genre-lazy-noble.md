# ADR 0004: 장르 전환 — 액션에서 "나태한 귀족의 영지 망하게 하기" 경영으로

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-11-12 |
| 상태 | **채택 (실험 단계)** — 숫자 시뮬레이션은 통과, 화면 실험판에서 재미 확인 예정 |
| 대체 | ADR 0002(3D)·0003(시점 전환)의 액션 방향을 **동결** |

## 배경

- 액션 게임은 그림·UI·캐릭터 동작·지형의 비중이 예상보다 훨씬 큼. 혼자서 분위기 있는 그림을 만드는 데 막힘.
- 아이디어 노트([idea-notes](../ideas/idea-notes.md))에서 5개 후보 중 **G1 "돈을 다 써야 끝나는 게임"**을 고름.
- 아이디어들의 공통 감각 = **익숙한 규칙을 뒤집기**.

## 결정

| 항목 | 결정 |
|---|---|
| 장르 | 경영 (하루 단위 턴제) |
| 전제 | 나태한 귀족이 던전이 있는 영지를 맡음. 돈을 벌면 왕실로 불려 가 귀찮아짐 → **들키지 않고 영지를 망하게** |
| 분위기 | **가벼운 코미디** — 망해도 아무도 진짜로 다치지 않는 세계, 망치려는 결정이 자꾸 대성공(착각계) |
| 핵심 축 | 금고(0 이하 = 파산 = 승리), 의심도(한계 = 태만죄), 번영도(한계 = 왕실 소환) |
| 화면 | 다키스트 던전의 영지처럼 **마을 구역 화면** ↔ **장부 화면** (장부를 꺼내 덮는 연출), 정보를 일부러 나눠 자주 오가게 |
| 길이 | 본편 60일(계절 4 × 15일, 계절마다 감찰) `[추정]`, 실험판은 봄 15일 |

## 근거

| 근거 | 내용 |
|---|---|
| 그림 부담 | UI·장부·구역 그림 몇 장이면 됨 → 혼자 완성 가능 |
| 강점 활용 | 경제 = 순수 로직 → 테스트·전략 봇으로 밸런스를 숫자로 검증 가능 |
| 아이디어 재사용 | "학습하는 보스" → **학습하는 집사** (같은 지출을 반복하면 집사가 미리 준비해 오히려 돈을 벌어 옴) |

## 기존 것 처리

| 대상 | 처리 |
|---|---|
| 3D·2D 액션 코드 (`src/three`, `src/scenes` 등) | **동결** (지우지 않음, 테스트는 계속 통과 유지) |
| 테스트·문서 체계·돌연변이 검사 | 그대로 |
| 학습 아이디어, 오염된 안내자 | 학습 → 집사로 사용. 오염된 안내자는 이후 이야기 후보 |

## 위험

| 위험 | 대응 |
|---|---|
| 정답 루틴 하나로 풀림 | 전략 봇으로 확인 → 실제로 "개축+경고문+기부" 반복 루틴이 발견돼 횟수 제한·반복 의심도·기부 감쇠 추가 |
| 숫자만 재밌고 화면은 지루 | 다음 단계: 구역 ↔ 장부 화면 실험판으로 확인 |
