# 2026-11-08 — 3D-2: 플레이어 마네킹, 거대 보스 몸체

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 플레이어 | 원기둥 → **테스트 더미 마네킹** (흰 몸 + 청록 관절) | 구르기·3타 준비·경직이 몸으로 읽혀야 함. "시뮬레이션 속 베타 테스터"와 맞음 |
| 보스 | 육각기둥 → **거대 관절 로봇** (키 274 = 플레이어 63의 약 4.3배) | 사람 모양 옆에 있어야 크기가 체감됨 |
| 스타일 | 보스 = 어두운 반투명 몸 + 붉은 윤곽선 + 가끔 깜빡임(홀로그램), 플레이어 = 단단한 흰 몸 | 둘이 한눈에 구분 → 나중에 "보스가 플레이어 색을 띤다"(학습 연출 §8 ③) 신호가 살아남 |
| 만드는 법 | 외부 모델 없이 기본 도형 + 관절, 자세는 순수 함수 | 내려받기·라이선스 없음, 자세를 테스트할 수 있음 |
| 판정 | **그대로** (보스 반지름 40, 플레이어 12) | 보이는 것만 바뀜. 무기 끝 = 2D 무기 자세의 닿는 거리 × 1.5 |

## 구조

| 파일 | 역할 |
|---|---|
| `entities/player/playerPose.ts` | 플레이어 자세 (대기·걷기·구르기·1/2타·3타 한 바퀴·구르기 공격·패링·피격·사망) |
| `three/Mannequin.ts` | 마네킹 메시, 자세 적용 |
| `entities/boss/bossBodyPose.ts` | 보스 몸 자세. 무기 방향은 기존 `weaponPose` 그대로, 팔은 "어깨 → 무기 끝이 닿을 점"을 향함 |
| `three/BossRig.ts` | 보스 메시(홀로그램 재질·윤곽선·외눈·가슴 코어), 무기 6종, 등장 잘라내기 |

## 몸짓 규칙 (보스)

| 상황 | 몸 |
|---|---|
| 준비 | 무기를 점점 높이 들고(처음 빠르고 끝에서 느리게) 몸을 낮춤. 강패턴은 더 낮추고 눈이 밝아짐 |
| 치켜드는 기술 | 두 팔 머리 위, 몸을 뒤로 젖힘 |
| 판정 | 앞으로 숙이며 무기 끝이 바닥 가까이를 쓸고 감 |
| 사격 | 총구를 플레이어 가슴 높이로 겨눔 |
| 쌍검·맨손 | 왼팔이 조준축 기준 대칭 |
| 자세 붕괴 | 한쪽 무릎 꿇고 고개 숙임, 눈이 어두워짐 (반격 기회) |
| 무기 교체 | 고개를 들고 몸을 세움 |
| 점프 | 다리를 접음 |
| 사망 | 0.9초 동안 앞으로 쓰러지고 눈이 꺼짐 |
| 등장 | 시작·처음부터(R, 5번째 사망) 때 2.2초 동안 아래에서 위로 그려지며 나타남. 이 동안 보스는 움직이지 않음 |

## 카메라

- 락온 중 바라보는 높이를 보스 키에 맞춰 올림 (멀리서도 머리까지, 가까울수록 더)
- 락온 표시를 무릎 높이 → 가슴 코어로

## 검증

| 방법 | 결과 |
|---|---|
| 테스트 | 193 통과 (자세 테스트 20개 추가) |
| 돌연변이 검사 | 플레이어 7개 + 보스 8개 바꿔치기 모두 잡힘 |
| 자세 갤러리 | 동작별 자세를 한 장에 그려 확인 (헤드리스). 구르기 때 머리가 바닥을 뚫음 → 머리를 무릎 쪽으로 마는 자세 추가, 칼이 너무 김 → 46→36 |
| 게임 화면 | 등장·락온(멀리/가까이)·회전 베기 준비·사격 준비 확인. 총을 바닥으로 겨눔 → 플레이어 거리로 겨누게 수정 |
| **테스트가 잡은 것** | "키가 플레이어의 4~5배" 테스트 실패 (실제 3.6배) → 몸 전체 1.2배 |

## 남은 것 / `[추정]`

- 몸 비율·색·홀로그램 깜빡임 빈도는 직접 보고 조정
- 흰 경기장 위의 홀로그램은 약함 → 어두운 경기장은 3D-4(이펙트) 때 같이 검토
- 보스 다리 폭(±43)이 판정 반지름(40)보다 살짝 넓음 → 다리를 때렸는데 안 맞는 느낌이 나면 조정
