# 2026-11-08 — 버그 수정: 3타 충전 중 되감기 지점이 저장되면 무한 사망

## 증상 (사용자 발견)

3타를 쓰다 죽으면, 되감은 뒤 3타 준비 동작 상태라 움직일 수 없어 같은 공격에 계속 죽음.

## 원인

- 되감기 지점 = "보스가 새 패턴을 시작하는 순간"의 플레이어·보스 상태 전체
- 그 순간 플레이어가 **취소할 수 없는 동작**(3타 충전, 구르기 끝 경직 등) 중이면, 그 상태까지 그대로 저장됨
- 되감을 때마다 같은 동작 → 같은 공격에 맞음 → 무한 반복
- 2D·3D 모두 해당 (되감기 로직 공유)

## 수정

`PlayerModel.recoverAfterRewind()`: 되감은 뒤 위치·스태미나는 그대로, 동작은 "아무것도 안 하는 상태"로. 스태미나는 최소 구르기 1회분 보장.

## 왜 테스트가 못 잡았나

되감기 테스트는 "저장한 상태로 정확히 돌아오는가"만 확인했다. **정확히 돌아오는 것 자체가 버그의 원인**이었다 → "되감은 뒤 바로 움직일 수 있는가"라는 플레이어 입장의 조건을 테스트로 추가.
