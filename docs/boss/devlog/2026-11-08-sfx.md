# 2026-11-08 — 효과음 (Web Audio 합성)

## 목표

소리 파일 없이 브라우저에서 합성한 효과음으로 타격감과 "읽는 단서"를 더한다.

## 구현

| 항목 | 내용 |
|---|---|
| `audio/sfxMap.ts` | 한 프레임의 이벤트(플레이어·보스·판정·씬) → 낼 소리 이름 (순수 로직, 테스트) |
| `audio/Sfx.ts` | Web Audio 합성기: 음높이가 미끄러지는 톤 + 대역 필터 잡음. 첫 키 입력·클릭 때 소리 장치를 깨움 (브라우저 정책). 실패해도 게임은 계속 |
| 소리 19종 | 휘두름(1·2타) / 무거운 휘두름(3타) / 찌름(대시 찌르기) / 대시 / 스태미나 부족 / 타격 / 패링(금속성) / 회피 / 자세 붕괴 / 쓰러짐 / 승리 / 보스 휘두름 / **조준 고정** / 무기 교체(글리치) / 총소리 / 땅울림 / 되감기 / 체크포인트 / 헬퍼 안내 |
| 규칙 | 같은 소리는 한 프레임에 한 번 / 쓰러진 프레임은 "맞음" 대신 "쓰러짐"만 / 원거리 타는 휘두름 없이 발사음만 |
| 조준 고정 소리 | 보스 조준이 고정되는 순간 짧은 "틱" → 바닥 예고가 줄어도(2c-3) 소리로 타이밍을 읽을 수 있음 |
| N 키 | 효과음 켜기/끄기 |

## 검증 `[검증됨]`

| 검증 | 결과 |
|---|---|
| 타입 검사 | 통과 |
| 테스트 | **152개 통과** (신규: 효과음 고르기 6) |
| 소리 실측 | headless Chrome에서 19종을 하나씩 오프라인 렌더링해 크기 측정 → 모두 소리 남, 오류 없음, 찢어짐 없음(최대 0.35) |
| 조정 | 잡음 계열(휘두름 등)이 톤 계열보다 4~5배 작게 측정됨 → 잡음 크기 2.5배 보정 후 재측정 (휘두름 0.05 → 0.12) |
| 미검증 | 실제로 들었을 때의 느낌 → 브라우저에서 확인 |
