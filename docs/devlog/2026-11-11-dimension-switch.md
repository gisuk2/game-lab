# 2026-11-11 — 방향 전환: 2D ↔ 3D 시점 전환 실험판

## 결정 ([ADR 0003](../adr/0003-dimension-switch.md))

- 블라스퍼머스식 2D 횡스크롤(정밀·타이밍)과 지금의 3D 소울류(공간·우회)를 **하나의 세계, 두 시점**으로 합침
- 전환: 보스가 강제로도 바꾸고(잠금), 플레이어도 게이지로 바꿈 / 2D는 깊이 투영 / 전환 순간 0.3초 무방비
- 다크 판타지로 세계관 전환 (기능 그대로, [스토리 §0](../design/story.md)), 체력 바 + 회복약

## 만든 것

| 영역 | 내용 |
|---|---|
| 판정 | 2D에서는 바닥 범위를 옆에서 본 좌우 구간으로 바꿔 판정 (깊이 무시). 높이 구간 추가 → 낮게 오는 공격·탄은 점프로 넘음 |
| 플레이어 | 점프(Space)·중력, 회복약(F), 구르기는 Shift로 이동, 3D 게임은 체력 바 |
| 시점 | 게이지(적중 +8, 패링 +25, 전환 −40), 강제 전환 잠금, 시점별 머문 시간 |
| 보스 | 칼날 벽(2D에선 못 피함), 탄막(낮은/높은 탄 번갈아, 2D로 바꿔 줌), 오래 머문 시점에 불리한 패턴을 더 고름 |
| 화면 | 카메라가 3D 3인칭 → 옆에서 아주 멀리·좁은 화각으로 0.4초 동안 넘어감 (공간이 납작해지는 느낌), 2D 범위는 세로 띠로 표시, 도트 화면 (P로 끄기) |

## 검증

| 방법 | 결과 |
|---|---|
| 테스트 | 218 통과 (+25) |
| 돌연변이 검사 | 투영·높이·게이지·잠금·선호 시점·점프·회복약·탄 높이·칼날 벽·탄막·시점 학습 바꿔치기 → 잡힘. 처음엔 "두 번 점프 금지"가 안 잡힘 → 꼭대기에서 다시 누르는 테스트로 보강. 직사각형 꼭짓점 하나 빼기는 다른 꼭짓점이 같은 값을 줘서 결과가 같음 (의미 없는 변이) |
| 시뮬레이션 | 칼날 벽: 2D에서는 경기장 9곳 모두 맞음, 3D에서는 깊이로 한 걸음(35)이면 피함. 조준 고정 뒤 765ms ≥ 전환 300 + 한 걸음 + 반응 여유 |
| 브라우저 실제 플레이 (헤드리스) | 탄막 → 2D로 강제 + 잠금(E 눌러도 안 바뀜) → 끝나면 풀림 / 칼날 벽: 2D에 머물면 35 피해, 예고 중 E + S 한 걸음이면 피해 0 |
| 화면 | 3D·전환 중간·2D·점프·회복약·칼날 벽(2D 화면 전체 빨강 / 3D 얇은 띠) 확인. 2D 카메라가 보스 볏을 자름 → 바라보는 높이 120→150 |

## 남은 것 / `[추정]`

- 게이지·무방비·칼날 벽 시간 등 수치는 직접 해 보고 조정
- 2D 시점 카메라의 좌우 따라가기, 2D에서 보스가 깊이로 움직일 때 어색한지
- 되감기·재시도 5회를 체력 바 체계에서 어떻게 쓸지 (지금은 그대로 둠)
- 그림: 지금은 홀로그램 로봇·마네킹 그대로 + 도트 화면. 판타지 외형·최종 모델 방식은 재미 확인 뒤
