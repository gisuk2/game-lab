### A단계

| 요청 | 구현 |
|---|---|
| 카드는 장부에 적기 / 취소, 장부에서 다시 눌러 취소 | `WeekPlan`: 서명 전까지는 적어 두기만. 미리보기 = 영지 복사본에 차례로 결재. 빼서 조건이 깨진 서류는 같이 빠짐 |
| 카드 설명이 부실 | `cards.ts`: 서류 21장마다 올린 사람·한마디·집사 말·숨은 효과. 효과 아이콘(금고·유지비·의심·번영·구역 수치·휴업), 조건·횟수 |
| 숨은 효과 | ❓ 표시 → 겪으면 풀림 (`discover`). 단서 캐릭터로 미리 푸는 건 B·C단계 |
| 뭐가 달라지는지 안 보임 | 위쪽 띠에 계획 반영 미리보기(빗금 + →값), 서명 뒤 건물 위 동전(쓴 돈·번 돈), 영지 전경 소품(분수·경고문·난간·동상·비계·깃발…) |
| 영지 현황 늘 보이게 | 위쪽 띠: 이름·주차 / 번영·의심·왕실 관심 / 금고·다음 보고. 금고 누르면 흐름 그래프 |
| 집사 수첩 크게 | 영지 신문(다키스트 던전 이벤트 창 느낌: 왼쪽 집사, 오른쪽 양피지) · 위험 알림 · 조언 · 기록 |
| 신문 | 서류마다 "얼마 쓰고 → 얼마 벌었다" + 그 구역 사람 인터뷰(직업·성·이름 랜덤) + [가 보기 →] |
| 조작 | 장부·수첩 버튼으로 열고 닫기, 바깥 누르면 닫힘, ESC, 건물 안에선 아래 가운데 [영지로], 서명하면 영지 전경으로 |
| 빈 결재 서명 | 집사 확인 창 |
| 글이 불편 | 단어 중간 줄바꿈 금지(keep-all), 글자 크기 12·14·16, 줄 간격 1.6 |
| 개발용 | DEV 튜토리얼 건너뛰기 → 2주차·분수대 결재·던전 안 |

### A2 (사용자 피드백: 금액이 안 와닿음, 신문 가독성, 카드 틀 통일, 두루마리)

| 요청 | 구현 |
|---|---|
| 금고를 누르면 돈 화면 | 장부 [금고 · 건물별 수지] 탭: 건물별 들어온/나간 돈 막대 + 줄마다 원인, 이번 주(서명하면)/지난주 결과 전환 |
| 기본 수입이 뭐에 영향받나 | 기본 × 요인 칩 (번영 ×1.17, 흥 2단계 ×1.24, 명성…). `incomeBreakdown` = 경제 모델과 같은 값 (테스트) |
| 번영·의심이 뭘 바꾸나 | 위쪽 띠 수치를 누르면 설명 창 (지금 배율, 패배 조건, 올리는/내리는 것) |
| 금고 화살표·그래프 모르겠음 | "서명하면 10,500"으로 글자 표시, 그래프는 "금고 vs 왕실 기준"(계단 점선, 기준 위 붉은 구역, 지금 표시, 범례) |
| 카드 상세 통일 | 한 틀: 구역·종류 / 이름·비용 / 확실한 효과표(▼ 좋음 초록, ▲ 나쁨 빨강) / 숨은 효과·조건 / 요청자·집사 말 / 버튼 |
| 신문이 뭐가 좋은지 모름 | 맨 위 요약(✔/✘ 지난주 금고, 다음 보고까지 남은 금액), 서류마다 판정 카드(앞으로 들어올 돈 포함한 결국 손익, 손익 막대, 의심·번영 칩) |
| 두루마리 느낌 | 장부·수첩·카드에 위아래 말린 막대 + 그을린 가장자리 + 얼룩 (그림 없이 CSS) |
| 조언 줄글 | 카테고리 6개 → 누르면 그 설명 |
| 성공/실패 도장 | 삭제 |
| 건물 위 동전 사라짐 | 다음 클릭까지 남김 + 장부 건물별 수지로 |
| (버그) 서명 뒤 화면이 위로 밀림 | 숨긴 장부 쪽으로 무대가 스크롤됨 → 스크롤 0 고정 |

### C단계 (밤새 진행)

- `tools/art/district_art.py`: 던전 입구·주점·저택·광장·성당 위에서 본 임시 도트 (`public/estate/d_*.png`)
- `scene.ts`: `planScene()`(순수 함수) = 누가 몇 명, 무슨 말 / `DistrictScene` = 돌아다니기·말풍선·설치물
  - 사람 수: 던전 = 입장료(휴업이면 관리인만), 주점 = 흥·번영, 저택 = 사치, 광장 = 번영(+축제), 성당 = 의심
  - 대사: ① **최신 신문 인터뷰의 그 사람이 실제로 있음(★)** ② 지난주 그 구역에 돈이 들어온 이유 ③ 지어 둔 시설 ④ 평소 말
  - 설치물: 분수(물 튐), 금화 상자(반짝), 경고문, 난간, 휴업 판자, 파티 깃발, 액자 반짝, 비계, 연회 음식, 동상, 축제 등불, 헌금함
  - 영지민을 누르면 말을 검 (B2 단서 캐릭터의 바탕)
- 테스트 4개: 인터뷰한 사람 = 장면 속 사람, 시설·행사 표시 주기, 사람 수가 상태를 따라감, 대사에 돈 들어온 이유
