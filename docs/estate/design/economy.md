## 1. 한 줄

나태한 귀족이 던전 영지를 **들키지 않고 파산**시키려 한다. 그런데 망치려는 결정이 자꾸 대성공한다.

## 2. 하루

| 시간 | 일 |
|---|---|
| 낮 | 열린 구역을 돌며 **지출 카드**를 최대 3장 결재 (돈은 바로 나감) |
| 밤 | 장부 정산: 기본 수입(저택 임대료·주점·던전 입장료) − 유지비 + **돌아오는 돈** + **집사의 준비** |
| 확인 | 의심도가 조금 잊힘(−2), 해금 확인, 승패 확인 |

## 3. 세 축

| 축 | 오르면 | 한계 |
|---|---|---|
| 금고 | — | **밤 정산 뒤 0 이하 = 파산 선고 = 승리** |
| 의심도 | 대놓고 낭비, 같은 낭비 반복 | 100 = 태만죄 (패배, 파산보다 먼저 판정) |
| 번영도 | 사람들이 즐거워지는 지출 (모든 수입 × (1 + 번영/120)) | 100 = 왕실 소환 (패배) |

기한(봄 15일)이 지나도 금고가 남아 있으면 실패.

## 4. 함정 (망치려는데 돈이 돌아옴)

| 함정 | 규칙 |
|---|---|
| 돌아오는 돈 | 카드마다 "며칠 뒤부터 며칠 동안 매일 얼마" (번영도 배율) |
| 학습하는 집사 | 같은 지출을 반복하면 그날 밤 `비용 × 0.3 × 이전 사용 수(최대 3)`를 벌어 옴 |
| 무료 입장 | 3일 동안 던전 수입 0 → 끝나면 소문이 나서 던전 명성 × 1.35 |
| 반복하면 눈치챔 | 의심도를 올리는 카드는 `기본 + 이전 사용 수 × 2` |
| 기부 감쇠 | 기부는 의심도를 내리지만 반복할수록 × 0.6씩 덜 씻김 |
| 횟수 제한 | 저택 개축 3번(더 늘릴 방이 없음), 무서운 경고문 2번 |

### 4.1 돈이 다 돌아오면 어떻게 다 쓰나 (설계 원칙)

"알고 보니 이득"이 모든 지출에 붙으면 절대 0원이 안 됨. 그래서 **돌아오는 돈에는 늘 빈틈이 있다** — 그 빈틈을 찾는 게 퍼즐.

| # | 빈틈 | 예 |
|---|---|---|
| 1 | **늦게 온다** | 돌아오는 돈은 며칠 뒤. 파산 판정은 그날 밤 → 마지막 며칠에 몰아 쓰면 돈이 돌아오기 전에 파산 (봇이 실제로 찾은 승리법) |
| 2 | **조건이 있다** | 술 파티의 홍보 효과는 던전이 손님을 받을 때만. 같은 날 "무서운 경고문"을 붙이면 홍보가 헛방 → **서로 상쇄하는 조합** 찾기 |
| 3 | **유지비는 영원하다** | 개축·고용은 매일 조금씩 영원히 빠짐 → 일찍 할수록 많이 빠짐 (대신 의심도) |
| 4 | **진짜 낭비는 수상하다** | 순수하게 사라지는 지출은 의심도가 큼 → 기부로 씻으며 섞어 써야 함 |
| 5 | **번영이 모든 수입의 배율** | 번영을 낮추면 모든 함정이 약해짐 (대신 망하는 티가 남) |
| 6 | **같은 걸 반복하면 집사가 학습** | 늘 새로운 조합을 써야 함 |
| 7 | **뒤로 갈수록 큰 지출이 열림** | 마탑 연구(실패 확정?), 원정선(침몰?), 큰 행사 — "망치려 한 행동"으로 해금 |
| 8 | **판마다 함정이 다르다 (이후)** | 이번 계절 모험가들은 분수를 좋아함 / 싫어함 → 구역에서 대사로 알아내야 함. 다시 해도 새로움 |

→ 지출의 절반쯤은 정말로 손해, 절반쯤은 함정. **어느 쪽인지는 구역에서 보고 알아내는 것**이 실력.

### 4.4 결재 서류 후보 (전체)

유형: **손해** = 진짜로 사라짐 · **함정** = 알고 보니 돌아옴 · **상쇄** = 다른 함정을 꺼뜨림 · **세탁** = 의심 씻기 · **대형** = 해금 뒤 큰 지출 · **도박** = 크게 잃거나 크게 벎

| 구역 | 서류 | 유형 | 겉보기 → 알고 보니 |
|---|---|---|---|
| 저택 | 호화 연회 | 함정 | 사치 → 귀족 답례품, 혼담 지참금까지 |
| 저택 | 미술품 수집 | 함정(늦게) | 사치 → 화가가 몰려 그림값 상승 |
| 저택 | 저택 개축 | 손해 | 매주 유지비, 수상함 |
| 저택 | 낮잠용 정원 | 손해 | 정원사 월급. 그럴듯해서 덜 수상 (축제 주엔 관광지가 됨) |
| 저택 | 전속 요리사 | 함정(구역 넘음) | 월급 → 요리사가 주점에 레시피를 팔아 주점 수입 증가 |
| 저택 | 거대 초상화 | 손해 | 순수 낭비, 꽤 수상 |
| 주점 | 공짜 술 파티 | 함정(구역 넘음) | 술값 → 던전 홍보·용사 사기 → 다음 주 던전 수입 증가. 던전이 막혀 있으면 헛방 |
| 주점 | 음유시인 고용 | 함정(늦게) | 월급 → 영지 노래가 퍼져 명성 |
| 주점 | 외상 탕감 | 손해 + 번영 | 돈은 사라지지만 주민이 좋아해 번영 상승 (모든 수입 배율) |
| 주점 | 술값 인하 | 손해(수입 감소) | 몇 주 수입 줄어듦 → 손님이 늘어 결국…? |
| 던전 | 던전 분수 | 함정 | 장식 → 모험가가 쉬어 가며 오래 머묾 |
| 던전 | 무료 입장 | 함정(늦게) | 입장료 포기 → 소문이 나서 이후 손님 폭증 |
| 던전 | 무서운 경고문 | 상쇄 | 손님 감소. 같은 주 술 파티·분수 효과를 꺼뜨림. 수상함 |
| 던전 | 안전 난간 | 손해 | 스릴이 없어져 모험가 감소. **그럴듯해서 안 수상** |
| 던전 | 몬스터 휴가비 | 손해 + 상쇄 | 던전이 텅 빔 → 수입 급감. 매우 수상 |
| 던전 | 보물 상자에 진짜 금화 | 함정(큼) | 돈을 버림 → 소문에 모험가 대거 몰림 |
| 광장 | 축제 | 함정 | 행사비 → 상인이 몰려 세금 |
| 광장 | 영주 동상 | 손해 / 함정 | 유지비, 수상 → 관광 명소가 되기도 |
| 성당 | 기부 | 세탁 | 의심 감소 (반복할수록 덜 씻김) |
| 성당 | 새 종 | 손해 + 세탁 | 경건해 보여 의심 조금 감소 |
| 특수 | 비서에게 휴가 | 상쇄(집사) | **집사의 학습을 초기화**. 휴가비 + 그 주엔 영주가 직접 일해야 함(?) |

### 4.5 "함정인 걸 알아도 고르게" 만드는 장치 (2026-11-12, 내 생각 + 정리)

**문제**: 공짜 술 파티가 장기적으로 손해(돈이 돌아옴)라는 걸 알면 다시는 안 고른다.

**① 월말 마감 (4주마다 왕실 세무 보고)**
| 마감 | 금고 상한 `[추정]` | 넘기면 |
|---|---|---|
| 4주차 | 9,000 이하 | 왕실 관심 +1 (경고 편지) |
| 8주차 | 5,000 이하 | 왕실 관심 +1 |
| 12주차 | **0 이하 (파산)** | 데모 결과 판정 |

왕실 관심 2 = 소환 (패배). → 마감 직전엔 **"지금 당장 줄이는" 지출이 꼭 필요** → 나중에 돈이 돌아오는 함정이라도 고를 이유가 생김. 대신 다음 달이 힘들어짐 = **지금 vs 나중** 선택.
장부에 "이번 마감까지 N주 · 상한까지 −2,400" 한 줄 추가.

**② 조건이 있는 서류**
| 조건 | 예 |
|---|---|
| 금고가 **적을 때만** | 빚내서 잔치 (금고 2,000 이하): 빚 = 마이너스 금고 → 파산을 앞당김 |
| 금고가 **많을 때만** | 거대 동상 (10,000 이상): 큰 한 방 |
| 의심도가 **낮을 때만** | 대담한 낭비 (의심 20 이하에서만 결재 가능) |

**③ 구역 수치 → 좋은 서류 열기 (조합)**
- 구역마다 수치 하나: 주점 **흥**, 던전 **명성**, 저택 **사치 소문**, 성당 **신앙**.
- 그 구역 서류를 고를수록 오름. 일정 단계(예: 3, 5)에 **강한 서류**가 열림.
  - 주점 흥 3 → "주점 결투 대회" (큰 상금 = 큰 손해) / 흥 5 → "영주 생일 연회 (일주일 내내)"
  - 던전 명성 3 → "던전 리모델링 공사 (한 달 휴업)" = 수입 차단
- **양날의 칼**: 수치가 높을수록 그 구역의 함정도 세짐 (흥이 높으면 술 파티 홍보 효과도 큼) → 강한 서류를 열려고 키우는 동안 함정이 커짐.
- 데모: 수치 3개(흥·명성·사치 소문) × 단계 2개로 시작.

## 6. 밸런스 확인 (v2: 주 단위·서류 21장·월말 마감, `npx tsx games/estate/scripts/sim-economy.ts --trace`)

|---|---|---|
| 아무것도 안 함 | 8주차 소환 (금고 48,600) | 가만히 있으면 쌓임 |
| 가장 비싼 것만 | 10주차 태만죄 | 의심 관리 필요 |

| 대놓고 낭비 | 12주차 태만죄 | 그럴듯하게 망쳐야 함 |
| 무작위 300판 | 승리 **0%** | 생각 없이 못 이김 |
| 한 장씩 계산 (마감 인식) | 12주차 파산 (−2,088) | 생각하면 이김 |
| 내다보기 | 12주차 파산 (−95), 서류 15종, **함정 11장** | 이길 길이 있고, 함정도 고르게 됨 |

**내다보기 봇의 흐름**: 1~2주 손해 서류(개축·경고문·난간) → **마감 직전(3~4주, 7~8주)에 함정(보물 상자·분수·무료 입장·미술품·요리사)을 몰아 써서 당장 금고를 낮춤** → 다음 달에 돌아오는 돈을 다시 처리 → 10주 강한 서류(던전 리모델링, 명성 3) → 11주 빚내서 잔치로 마무리.

| 하루 단위 → 주 단위 첫 수치 | 수입이 너무 커서 내다보기도 실패 | 기본 수입 절반 이하로 |
| 수입 줄임 | 2~4주 만에 파산 (시작 금고를 한 주에 다 씀) | 파산 선고를 12주차 감찰로 |
| 마감만 있음 | 이기는 봇이 함정을 거의 안 씀 (비서 휴가 4번 반복으로 해결) | 비서 휴가 2번 제한 → 마감 직전에 함정을 쓰게 됨 |

### 7.2 발견하는 흐름 (핵심)

1. "던전 옆에 화려한 분수? 이건 분명히 돈 낭비야!" → 결재
2. 다음 날 장부: 돈이 **늘어 있음** + 비서: "훌륭한 결정이었습니다."
3. 플레이어: "뭐지?" → 장부를 내리고 → 영지 전경 → 던전 구역을 누름
4. 구역 안: **분수가 생겼고**, 모험가들이 분수 옆에서 쉬며 "분수가 생겨서 분위기가 너무 좋아", "힘들 때 쉴 수가 있어서 편해" → 이유를 **눈으로 발견**
5. 그걸 보고 다음 망치는 법을 궁리

→ **이유는 표나 설명문이 아니라 장면과 대사로만** 알려 줌. 장부는 결과만, 구역은 이유만 → 오가게 됨.

## 9. 경제 v3 초안: 새 수치 · 조합 시너지 · 결재 요청 분리 (B1, 검토용 — 아직 구현 안 함)

> 2026-11-12 사용자 요청: "카드끼리 조합할수록 달라지게, 숨겨진 시너지를 많이. 억지 문맥 말고 수치·숨은 조건으로. 도감에서 이득/손해 조합을 하나씩 찾아내게."
> 모든 수치는 [추정] — 전략 봇으로 균형 맞추며 바뀜.

### 9.1 새 수치 2개

| 수치 | 뜻 | 무엇이 바꾸나 | 무엇에 영향 |
|---|---|---|---|
| 👥 영지민 수 (처음 120) | 영지에 사는 사람 | 축제·외상 탕감·술 파티 +, 경고문·무거운 세금·리모델링 소음 − | 주점 세금·저택 임대료 = 기본 × (영지민/120). **80 아래면 매주 의심 +3** ("영지가 텅 비었다") |
| ⚔ 모험가 수 (처음 30) | 매주 던전에 오는 사람 | 분수·금화·파티 소문·음유시인 +, 경고문·난간 −, 휴업 0 | 던전 입장료 = 모험가 × 단가(75). 지금의 '던전 명성 배율'을 사람 수로 보이게 바꾼 것 |

→ 위쪽 띠에 두 수치를 늘 보이게. 카드 효과표에 "⚔ 모험가 +6/주" 같은 줄이 생김.

### 9.2 조합의 세 종류

1. **같은 주** — 둘을 같은 주에 결재
2. **남아 있는 것 + 새 서류** — 예전에 지은 시설·고용한 사람이 있을 때
3. **수치 조건** — 영지민·모험가·의심·번영·구역 수치가 몇 이상/이하일 때만

발견: 조합이 처음 일어나면 신문에 "🔗 조합 발견! 「이름」", 장부 건물별 수지에 조합 줄이 따로 찍힘 → 장부 [서류 도감] 탭 '조합' 장에 이야기·조건·효과가 모두 적힘. 못 찾은 조합은 "??? (주점 + ?)"처럼 반쪽 힌트.

### 9.3 조합 목록 초안 (24개: 이득 = 돈이 빠짐 / 손해 = 돈이 벌림)

| # | 이름 | 조건 | 효과 | 돈 | 왜 |

### 9.4 결재 요청 분리 (사용자 결정)

- 올라온 결재 요청: 줄마다 바로 [승인] [반려]. **서명 전까지 바꿀 수 있음**. 결재 3칸은 안 씀. **모두 결정해야 서명**.
- 건물에서 적은 일만 결재 3칸.
- 요청은 매주 2건 → 돈 쓸 기회가 늘어남 → 봇 균형 다시.

### 9.5 집사 학습 (재설계 필요 — 사용자: "컨셉은 좋은데 와닿지 않음")

후보: 같은 서류를 다시 하면 집사가 수습해서 비용 일부를 되찾아 오되, **장부에 이유가 있는 줄로**(연회 → "남은 음식을 시장에 팔았습니다 +720", 미술품 → "그림 대여료", 개축 → "남은 자재를 되팔았습니다") 찍히고, 카드에 "집사가 이 서류를 1번 봤음 → 다음엔 30% 되찾아 옴"이 미리 보임. 비서 휴가로 잊게 함. — 결정 보류.
