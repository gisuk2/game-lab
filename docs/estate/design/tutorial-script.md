## 1. 원칙

| 원칙 | 내용 |
|---|---|
| **두 번 설명** | 집사가 시스템을 **정석대로** 설명 → 바로 이어서 주인공이 **속으로 거꾸로** 해석. 규칙 배우기가 곧 코미디 |
| 한 화면 = 한 가지 | 한 단계에서 버튼 하나, 개념 하나만 |
| 짧게 | 말풍선 한 번에 두 줄 이내 |
| 잠그고 열기 | 지금 배울 버튼만 빛나고, 나머지는 잠김 |
| 건너뛰기 | 두 번째 판부터는 "튜토리얼 건너뛰기" |
| 독백 표시 | 주인공 속마음은 다른 말풍선 (점선 테두리 + 기울임), 집사에게는 안 들림 |

## 4. 구현 메모

- **v0.3 화면 규칙**: 대사창은 항상 아래 고정(집사 버튼과 장부 버튼 사이), 장부·수첩은 대사창 위 공간만 씀 → 위쪽 HUD(금고·주차)와 안 겹침 (헤드리스로 좌표 검사).
- **강조**: 손가락 아이콘 없음. 화면을 살짝 어둡게(행동 단계 34%, 설명 단계 18%) + 눌러야 할 곳만 밝게 깜빡.
- **결재함**: 1주차는 고정(저택 서기 휴가 → 분수대). 2주차부터 `weeklyInbox()`가 매주 2건 (결재 가능한 것만, 지난주 것 제외, 대형·마무리 제외).
- **집사 수첩**(왼쪽 아래): 이번 주 소식(돈이 들어온 이유 → 집사 한 줄) · 집사의 조언 · 대화 기록.

| 항목 | 내용 |
|---|---|
| 대본 데이터 | 단계마다 `{ 화자, 대사, 강조할 UI, 열어 둘 버튼 }` 목록 → 화면이 차례로 재생 |
| 1주차 고정 | 튜토리얼 1주차 서류는 분수대 한 장, 반려 잠김 (경제 모델 그대로: 분수대 → 다음 주 돌아오는 돈 + 이유 태그 `fountainRest`) |
| 2주차 반전 | 경제 모델의 실제 결과로 장부가 플러스가 되는지 테스트로 고정 (수치를 바꿔도 반전이 깨지지 않게) |
| 건너뛰기 | 첫 판을 끝낸 뒤 시작 화면에 표시 |
